## 1. 产品概述
DeVPN Android 客户端 UI。采用 React + Vite 构建的移动端 Web 应用，设计为可嵌入 WebView 或作为 PWA 安装。界面采用浅色模式，核心视觉为大型点阵（Dot Matrix）区域展示连接状态，配合液态玻璃（Liquid Glass）效果卡片，整体风格精致现代。

## 2. 核心功能

### 2.1 功能模块
1. **主页（首頁）**：点阵状态可视化、连接控制、IP/延迟/性能信息展示。
2. **节点列表（節點）**：服务器节点列表、延迟测速、节点选择。
3. **设置（設置）**：应用设置、关于、主题切换（预留）。

### 2.2 页面详情
| 页面名称 | 模块名称 | 功能描述 |
|---------|---------|---------|
| 主页 | 点阵状态区 | 大型点阵背景，中央显示状态图标（✅ 绿色已连接 / 🔵 蓝色转圈连接中 / ❌ 红色叉连接失败） |
| 主页 | 信息卡片区 | 液态玻璃效果卡片，展示 IP 地址、延迟(ms)、内存/性能占用 |
| 主页 | 连接按钮 | 大圆角按钮，文字根据状态变化（开始/断开） |
| 节点列表 | 节点卡片 | 节点名称、地区、延迟数值、选中状态 |
| 设置 | 设置项 | 分组列表，开关、箭头导航 |

## 3. 核心流程
用户打开 App → 主页展示点阵区域（初始状态：连接失败/未连接）→ 点击"开始" → 状态变为连接中（蓝色转圈）→ 模拟连接成功后变为已连接（绿色勾）→ 信息卡片展示 IP、延迟、性能数据 → 点击"断开"恢复初始状态。

## 4. 用户界面设计

### 4.1 设计风格
- **主题**：浅色模式（Light Mode），背景为柔和的灰白渐变
- **背景色**：`#F5F7FA` 到 `#E8ECF1` 的微妙渐变
- **主色**：`#007AFF`（蓝色，连接中、按钮）
- **成功色**：`#34C759`（绿色，已连接）
- **错误色**：`#FF3B30`（红色，连接失败）
- **文字色**：`#1C1C1E`（主文字），`#8E8E93`（次要文字）
- **液态玻璃效果**：卡片使用 `backdrop-filter: blur(20px) saturate(180%)`，半透明白色背景 `rgba(255,255,255,0.65)`，配合 1px 白色高光边框
- **点阵区域**：深色点阵网格（`#2C3E50` 点阵在 `#F5F7FA` 背景上），中央悬浮状态图标
- **字体**：系统默认无衬线字体，SF Pro / Roboto 风格
- **布局**：底部三栏 Tab 导航（主页、节点、设置）

### 4.2 页面设计概述
| 页面名称 | 模块名称 | UI 元素 |
|---------|---------|---------|
| 主页 | 顶部栏 | 标题 DeVPN，极简风格 |
| 主页 | 点阵状态区 | 占据屏幕 40-50% 高度，Canvas/CSS 点阵背景，中央大图标 |
| 主页 | 信息卡片 | 液态玻璃效果，三列或两列布局：IP、延迟、性能 |
| 主页 | 连接按钮 | 底部悬浮或内容区底部，大圆角，颜色随状态变化 |
| 节点列表 | 搜索栏 | 顶部搜索输入框 |
| 节点列表 | 节点项 | 左侧国旗/图标，中间名称和延迟，右侧选中标记 |
| 设置 | 分组 | 圆角卡片分组，带图标和箭头 |

### 4.3 响应式
- 针对移动端竖屏 360dp-480dp 宽度优化
- 底部导航固定，安全区域适配
- 点阵区域高度使用 vh 单位自适应
