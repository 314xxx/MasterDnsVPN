## 1. 产品概述
DeVPN Android 客户端的 UI 展示应用。基于 WebView 的混合应用壳，内部加载本地前端资源，实现与截图一致的浅色模式界面。目标是为现有 VPN 后端提供一个可直接打包的 Android 前端壳。

## 2. 核心功能

### 2.1 功能模块
1. **首页（首頁）**：展示连接状态、推广横幅、快速连接按钮、节点选择、分流模式选择。
2. **会员（會員）**：会员状态、套餐列表、购买入口。
3. **我的（我的）**：用户信息、设置、关于、退出登录。

### 2.2 页面详情
| 页面名称 | 模块名称 | 功能描述 |
|---------|---------|---------|
| 首页 | 状态栏 | 显示连接状态（已停止/运行中），红/绿指示点 |
| 首页 | 推广横幅 | 轮播横幅，文案"一次推廣，雙重收益" |
| 首页 | 连接控制 | 大按钮"快速連接"（蓝）/"斷開連接"（红），点击切换状态 |
| 首页 | 节点选择 | 卡片显示当前节点（香港 HK），点击进入节点列表 |
| 首页 | 分流模式 | 卡片显示"智能分流"及描述，点击进入模式选择 |
| 会员 | 套餐列表 | 展示会员套餐、价格、购买按钮 |
| 我的 | 用户中心 | 头像、昵称、设置项列表 |

## 3. 核心流程
用户打开 App → 首页展示当前连接状态（已停止）→ 点击"快速連接" → 状态变为运行中，按钮变红显示"斷開連接" → 可切换节点或分流模式 → 点击"斷開連接"恢复已停止状态。

## 4. 用户界面设计

### 4.1 设计风格
- **主题**：浅色模式（Light Mode），以白色/浅灰为底色
- **主色**：蓝色 `#007AFF`（连接按钮、选中状态）
- **强调色**：红色 `#FF3B30`（断开连接按钮、停止状态）
- **成功色**：绿色 `#34C759`（运行中状态指示）
- **背景色**：白色 `#FFFFFF`，页面背景浅灰 `#F2F2F7`
- **卡片**：白色背景，圆角 16px，轻微阴影
- **字体**：系统默认无衬线字体，标题加粗
- **布局**：底部三栏 Tab 导航，内容区卡片化

### 4.2 页面设计概述
| 页面名称 | 模块名称 | UI 元素 |
|---------|---------|---------|
| 首页 | 顶部栏 | 左右图标（礼物、free），标题 DeVPN，状态指示 |
| 首页 | 推广横幅 | 轮播图，分页指示器 |
| 首页 | 连接区域 | 状态文字（會員已過期/免費流量生效中），大圆角按钮 |
| 首页 | 功能卡片 | 节点卡片（国旗+文字+箭头），分流卡片（图标+文字+箭头） |
| 会员 | 套餐卡片 | 价格、时长、权益列表、购买按钮 |
| 我的 | 列表项 | 图标+文字+箭头，分组展示 |

### 4.3 响应式
- 针对移动端竖屏设计，适配 360dp-480dp 宽度
- 底部导航固定，内容区可滚动
